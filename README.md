# СДПН — Telegram Mini App «Пройти обследование»

```
miniapp/
├─ index.html            ← всё приложение (HTML + CSS + JS)
├─ stories/*.jpg         ← 19 готовых карточек 1080×1920 для «В сторис» (по одной на трек)
└─ tools/save_server.py  ← локальный сервер: превью + генерация карточек
```

## Что поправить перед публикацией

Всё лежит в объекте `CONTENT` в начале `<script>` в `index.html`:

- `links.channel` — ссылка на канал (`https://t.me/...`).
- `links.miniApp` — ссылка на само приложение (`https://t.me/<бот>/<app>`), появится после шага 3 ниже.
- `tracks.<id>.url` — ссылки на треки. Пока ссылка пустая, кнопка «Принять назначение» ведёт в канал.
- Любые тексты: вопросы, ответы, диагнозы, обоснования.

Если поменяли тексты диагнозов или названия треков, перегенерируйте карточки для сторис:

```
python tools/save_server.py
```
Затем откройте http://localhost:8765/?export=stories. Все 19 строк должны быть с ✓.

Проверка распределения (20 000 случайных анкет): http://localhost:8765/?sim. Если в `missing` что-то есть, этот трек никому не выпадает.

## 1. Хостинг на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на github.com и нажмите **New repository**. Назовите его, например, `sdpn`, сделайте **Public** и нажмите **Create**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите **содержимое папки `miniapp`**: `index.html` и папки `stories` и `tools`. Нажмите **Commit changes**.
   > mp3/wav сюда не кладите: приложению они не нужны.
3. Откройте **Settings → Pages**. В **Source** выберите `Deploy from a branch`, ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Через 1–2 минуты появится адрес вида `https://<логин>.github.io/sdpn/`. Откройте его в браузере и проверьте, что всё работает.

Альтернатива: Netlify (app.netlify.com → **Add new site → Deploy manually** → перетащить папку `miniapp`). Адрес будет `https://<имя>.netlify.app`.

## 2. Бот

1. В Telegram откройте **@BotFather** и отправьте `/newbot`. Придумайте имя, например «СДПН · Регистратура», и username, который заканчивается на `bot`.

## 3. Мини-приложение (прямая ссылка t.me/<бот>/<app>)

1. В @BotFather отправьте `/newapp` и выберите своего бота.
2. Название: `Пройти обследование`. Описание: «Центр музыкальной психотерапии «СДПН». Пройдите обследование и получите назначение».
3. Фото 640×360 (можно скриншот стартового экрана). GIF пропустите командой `/empty`.
4. **Web App URL**: адрес с GitHub Pages, например `https://<логин>.github.io/sdpn/`.
5. **Short name**: например `exam`. Ссылка на приложение будет `https://t.me/<бот>/exam`.
6. Впишите её в `CONTENT.links.miniApp` и заново загрузите `index.html` на GitHub.

## 4. Кнопка меню у бота

1. В @BotFather: `/mybots` → выберите бота → **Bot Settings → Menu Button → Configure menu button**.
2. Отправьте URL (тот же адрес GitHub Pages), затем текст кнопки: `Обследование`.

Теперь у бота слева от поля ввода есть кнопка, которая открывает приложение. В посты канала ставьте ссылку `https://t.me/<бот>/exam`.

Можно включить и полноэкранный режим: `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App** и указать тот же URL. Тогда приложение появится в профиле бота кнопкой «Открыть».

## Как работают сторис

`Telegram.WebApp.shareToStory()` принимает картинку **только по публичной https-ссылке**, а без бэкенда персональную картинку негде разместить. Поэтому:

- **«В сторис»** в Telegram публикует готовую карточку трека из `stories/<id>.jpg` с хостинга. На ней стоит «Ф.И.О.: Неизвестно», что подходит по концепции. Если в карточке указан `links.miniApp`, у Premium-пользователей к сторис добавится ссылка-виджет на приложение.
- Если Telegram старый (ниже 7.8), приложение открыто в браузере или карточки нет, показывается **персональное** заключение (номер, имя), чтобы сохранить его и выложить вручную.
- **«Сохранить»** рисует персональную картинку через canvas. В Telegram 8.0+ кнопка «Скачать» сохраняет готовую карточку трека через нативное скачивание. На телефоне без Telegram открывается системное меню «Поделиться», на компьютере файл скачивается. Картинку также можно сохранить долгим нажатием.
